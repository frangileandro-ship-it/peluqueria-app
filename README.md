# 💇‍♀️ Peluquería AC - App de Gestión

Aplicación web para la gestión de una peluquería, desarrollada con Streamlit y conectada a Google Sheets.

## 🚀 Funcionalidades

- 📊 **Dashboard:** Visualización de ingresos, gastos, ganancias y top clientes.
- 💸 **Movimientos:** Registro y gestión de ingresos y egresos.
- 📅 **Turnos:** Agenda de turnos con calendario interactivo.
- 💰 **Caja:** Gestión de saldos de efectivo y Mercado Pago.
- ⚙️ **Configuración:** Maestro de datos (clientes, proveedores, categorías, medios de pago).

## 🛠️ Tecnologías

- Python 3.12
- Streamlit
- Google Sheets API (gspread)
- Plotly (gráficos)
- Pandas
